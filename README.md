# Remix of Pixel Perfect Hero

Recreate this hero exactly in Next.js + Tailwind. Focus on layout, spacing, typography, responsiveness, and subtle animations. Do not change the design. That was a hero section of a landing page, so i wan the exact same output of the image.

This project is a smart home automation ecosystem called Zenith.
## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
